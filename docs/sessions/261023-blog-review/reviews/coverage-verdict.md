## 一、素材覆盖缺口（按价值降序）

### 缺口 1【高】「做法确定就固化成脚本，不确定才让 Agent 试」的分工原则

- **素材**: 261021-阿甘对话02.srt（约 00:16:45–00:17:07）
  > 「一个脚本啊，定期去同步就好了，每天同步一下。」
  > 「就是如果这个东西是确定的话，那就不会让Agent来跑。只是不确定的时候，才可能先用Agent来点。」
- **为什么值得写**: 这是作者亲口说出的**通用分工判据**：脚本管确定的，Agent 管探索的。它一句话回答了老板「什么活交给脚本、什么活交给 Agent、两者怎么演化」的高频疑问，也把第六节投放案例（浏览器土办法→API 正规化）和第七节「收编」从个例提升为可复用的规则。草稿目前只有「收编」的动作描述（380、389 行），没有这条原则本身。
- **插入位置**: 第 389 行「先有人走出路来，公司再修路」段之后（备选：第 180 行「方式可以粗糙，先接进来再说」之后）。
- **建议成稿**:
  > 这里面还有一条好用的分工规矩：**一件事只要做法已经确定，就沉淀成脚本，让机器直接跑，不再让 Agent 每次现场发挥；做法还没定型的，才先让 Agent 去试。** 试出路来了，再固化成脚本和工具。Agent 是探路的，不是永远在路上。

### 缺口 2【高】上下文攒够后，模型能给出「业务认知之外」的洞察

- **素材**: 261021-阿甘对话02.srt（约 00:13:26）；260930-思考.txt
  > 「原则上应该AI可能几十个数据源，我都丢给更牛逼的模型，我让它来分析一下到底，OK，它可能跟你分析出来，原来这个销量降了，可能跟哪些因素有什么关系。」（对话02）
  > 「那可能就是你组织内部的数据源到达一定的程度之后，它甚至可以挖掘出你一些意想不到的角度，可以，比如说帮助你规避一些供应链的上面的风险啊之类的信息。」（思考）
- **为什么值得写**: 这是「模型越强、你越受益」最具体、最诱人的兑现方式，也是老板攒数据最直接的回报想象：不只复盘已知问题，还能在业务认知之外发现关联、提前避险。草稿只有抽象版本（第 219 行「迟早会超过你，至少一定能给你启发」），缺这个具体承诺。
- **插入位置**: 第 227 行「两个直接的收益」节末尾，作为第三项收益补入。
- **建议成稿**:
  > 而且上下文攒到一定程度，还会有意外的惊喜：把几十个数据源一起交给最强的模型，让它分析「这个月销量为什么掉了」，它找出的关联因素可能完全在你的业务认知之外，甚至能提前提示某个供应链上的风险。这种「意想不到的角度」，只有把信息喂够了才会出现。

### 缺口 3【中】理想、小米也在依赖飞书——回应「外部产品风险」的现成先例

- **素材**: 261021-阿甘对话02.srt（约 00:18:03）
  > 「但是如果说涉及到跟人进行的交互，就依赖飞书就已经是最合适的方案。因为就像那些理想啊、小米啊，他们本身上很多也都是依赖飞书来做这些事。」
- **为什么值得写**: 草稿第 164 行高管质疑「把核心业务依赖在一个外部产品上，是不是有风险」，第 166–170 行的三点回答全是说理。对「土老板」读者，一句「理想、小米也这么做」的权威先例往往比三条论证更有说服力，且素材里现成、零虚构成本。
- **插入位置**: 第 169 行「算一下自己开发的账」条目内或紧随其后。
- **建议成稿**:
  > 顺带一个现成的参照：理想、小米这类公司，内部协作同样大量依赖飞书。把人和 Agent 共用的协作层放在成熟产品上，不是小公司的将就，而是行业里的主流做法之一。

### 缺口 4【中】素材闭环：线下拍摄也能进数据循环的具体案例

- **素材**: 261021-阿甘对话02.srt（约 00:08:07、00:10:20）
  > 「那原则上是不是可以说，我从基础的这些现实世界里拍出的素材，然后把它们拼接组合成一个新的素材投出去，然后最后把数据回转回来。」
  > 「对，最重要的，最重要的一定是达成一个循环。……即便它最开始出点垃圾，但是它只要在迭代它就OK。但是如果这个循环里缺了一角，那这个问题就有问题了。」
- **为什么值得写**: 草稿里的闭环例子（帐篷差评、补货巡检）都围绕「货」；素材闭环是「纯物理的创作活动进数字循环」的第二种形态，向老板演示了 Loop 概念如何套在非数字业务上。「缺一角就危险、起点垃圾没关系」这句话也很有传播力。注：素材中这是正在规划/起步的方向，成稿措辞需如实。
- **插入位置**: 第 227 行后（与缺口 2 相邻，可合并成「收益三、收益四」）。
- **建议成稿**:
  > 闭环也不只盯着货。我们正在把线下拍素材这条线也接进循环：脚本和素材放到指定位置，广告投出去后拿回完播率数据，让模型定位「超级画面」出在哪一秒，再反过来指导下一轮拍什么场景、什么风格。这种循环哪怕起点很粗糙，只要转起来就会越滚越好——真正危险的不是起点低，而是循环缺了一角。

### 缺口 5【中】业务的原点搬到了表上：先有飞书行，才有商品库

- **素材**: 261021-阿甘对话01.srt（约 01:53:25–01:53:42）
  > 「首先是〔首先〕飞书表销〔就是〕飞出多表格〔多维表格〕里面先有特款〔测款〕商品，他才有可能定到商品库。所以最开始信息我们这里就已经有了哦。」
  > 「这个就是相当于这个工作流已经变开放，先不是在我们的内部系统里面开始原点都变成了从飞书里面开始吧。」
- **为什么值得写**: 草稿把飞书多维表格定位为「人和 Agent 共用的表」（镜像既有业务信息），素材里的事实更进一步：**表成了业务的起点**——测款商品先在表里出生，跑得通才进正式商品库，大量测款商品永远走不到上架那一步，但信息完整留在表里。这把第 150 行的判断从「协作工具」抬到「系统 of record」，是对飞书建议最有力的实证。
- **插入位置**: 第 144 行「以商品为中心聚合起来」段之后。
- **建议成稿**:
  > 用到后来，业务的起点干脆搬到了表上：一个商品先在多维表格里建档、测款，跑通了才进公司正式的商品库。大量测款商品根本走不到上架那一步，但它们的信息同样完整地留在表里——这是一套以「已上架商品」为中心的内部系统装不下的。

### 缺口 9【低】模型按业务场景各配各的，选型用业务结果回溯验证

- **素材**: 261021-阿甘对话02.srt（约 00:22:40、00:23:11）
  > 「我们本身有很多模型，但是我们比如说像翻译的话可能就用DeepL。然后如果是那个满意度标点的话，就用Gemini，就是你要平衡那个成本和质量。对，还是根据那个业务场景来做的。」
  > 「因为那个客服场景用的是GPT的。对，因为那个我们回溯过，就是DeepL在这种场景下表现很差。」
- **为什么值得写**: 草稿的模型分层讲的是「人分层」（执行 vs 决策）；素材补了另一根轴——**同一套业务里不同任务各配各的模型，且选型对错要拿业务结果回看**。后者本身就是一个微缩闭环，对正在选型的老板很实用。
- **插入位置**: 第 400 行「决策这块」条目之后、第 402 行折中办法之前或之后。
- **建议成稿**:
  > 另外，模型是跟着任务配的，不是一刀切：同一套业务里，翻译、满意度标注、客服对话各用各的模型，按成本和质量平衡。选型对不对，用业务结果回看——我们回溯过某个翻译场景，发现原来用的模型表现很差，当场就换了。

### 缺口 10【低】Palantir 的学习复用机制：挑乙方先问「沉淀了什么」

## 二、素材原意被写偏的地方

### 偏差 1【中】「90% 的代码是 Agent 在写」：素材说的是「10% 的人还在手写」

- **草稿**: 第 37 行「OpenAI 和 Anthropic——都在官方材料里公开说过：公司内部大约 90% 的代码，已经是 Agent 在写。<!-- TODO(核查) -->」
- **素材原文**: 260930-思考.txt
  > 「就比如说像 OpenAI 和 Anthropic 内部的，可能只有 10% 的人还在手写代码，这群什么百万年薪的程序员，可能也只有 10% 的人会还在手写算子，可能 90% 的场景都是在 AI 在来做这个 Coding 的工作了。」
- **偏差说明**: ①素材是「人」的比例（约一成的人还在手写）且三处带「可能」；草稿改成「90% 的代码已经是 Agent 在写」，从人的比例偷换成代码量比例、从推测升格为断言，命题被显著加强。②「都在官方材料里公开说过」这一出处形态素材里没有，属转述升级；且 TODO 至今未补链接。
- **建议**: 按 TODO 找到两家官方出处并核对口径；补不上就退回素材的弱表述，如「据公开报道，这两家公司内部可能只有约一成的工程师还在手写代码」。

### 偏差 2【中】「你要什么我不知道……」的发言人归属很可能写反

- **草稿**: 第 263–265 行「那位高管在聊天时一针见血地替他们说出了心里话：**『你要什么我不知道，你要的这些东西对我有什么用我也不知道，但你非要我表演给你看。』**」
- **素材原文**: 261021-阿甘对话02.srt（00:05:00–00:06:16，无说话人标注）
  > 高管追问：「那站在一个供应链的同学的角度，就比如说辉哥〔=供应链同事〕站在他的角度，给他带来什么价值。」「但现在我听下来，就是我们对于辉哥，他觉得什么东西有用是没概念的。」
  > 接话方（按对话逻辑为作者本人）：「……他get到的就是我想要什么，你不知道，但是你要什么，在我看来对我是没有价值的。」「然后你非要我表演给你看，然后就显得摩擦成本特别高……但是他觉得我靠，搞这些东西，我另外一个产品都搞完了。」
- **偏差说明**: 这句金句出现在高管追问「这对一线有什么价值、我们也没概念」之后，从对话走向看更可能是**作者在替一线说出感受**，而非高管的即席原话。草稿把发言人归给高管，若与事实不符，反而削弱了「连高管都替一线问出了这个问题」这层更真实的张力。
- **建议**: 二选一改写——①不点名发言人：「聊天时被一针见血地点破了：……」；②改引高管的追问并让作者认账：「那位高管问我：这对供应链同事自己有什么价值？我答不上来。他们的感受大概就是：你要什么我不知道……」（SRT 噪声大、无说话人标注，此判断置信中高，建议作者凭记忆定稿）。

### 偏差 3【低】Advisor 模式从「已配备」弱化成「可选建议」

- **草稿**: 第 402 行「对一线员工，还有一个省钱的折中办法：日常杂活全让便宜模型干……」
